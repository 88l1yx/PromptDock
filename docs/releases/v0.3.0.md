# PromptDock v0.3.0

## 简体中文

### 新功能

- 标签栏下方新增多个扁平文档文件夹。
- 拖动标签到文件夹图标即可保存；拖动经过时目标文件夹会放大。
- 点击文件夹可以查看内部保存的文档。
- 打开已保存文档时会作为第一个标签展示。
- 关闭打开的文档标签不会删除文件夹中的副本。
- 语法模式下拉菜单改为向上展开，始终保持在窗口内部。

### 修复

- 修复鼠标停在屏幕侧边但不在窗口高度范围内时，窗口反复收回、弹出的问题。
- 文件夹和保存文档会随 `workspace.json` 一起持久化。

## English

### New

- Added multiple flat document folders below the tab rail.
- Drag a tab onto a folder to save it; the target folder enlarges during the drag.
- Open a folder to browse its saved documents.
- Saved documents open as the first tab.
- Closing an opened document tab does not delete its folder copy.
- The syntax menu now opens upward and stays fully inside the window.

### Fixed

- Fixed repeated collapse/reveal when the pointer touched the screen edge outside the retracted window height.
- Folders and saved documents are persisted together in `workspace.json`.
