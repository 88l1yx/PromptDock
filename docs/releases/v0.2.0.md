# PromptDock v0.2.0

## 简体中文

### 新功能

- 新增左侧吸附，窗口现在可以停靠到显示器左边或右边。
- 左停靠时，窗口会向左收起，并在屏幕左侧保留 6px 绿色边缘条。
- 鼠标靠近左缘任意高度时自动展开左停靠窗口。
- 保留右侧吸附、拖动过程中不反复吸附、顶部固定加号和全部编辑功能。

### 下载

- `PromptDock-Portable-0.2.0-x64.exe`：无需安装。
- `PromptDock-Setup-0.2.0-x64.exe`：安装版。

## English

### New

- Added left-edge docking in addition to the existing right-edge docking.
- A left-docked window collapses toward the left and leaves a 6px green strip on the left side of the display.
- Moving the pointer to any height on the left display edge reveals the left-docked window.
- Existing right docking, drag-away behavior, fixed top add button, editor, and themes remain unchanged.

### Downloads

- `PromptDock-Portable-0.2.0-x64.exe`: portable.
- `PromptDock-Setup-0.2.0-x64.exe`: installer.
