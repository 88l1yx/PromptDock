# PromptDock v0.1.3

## 简体中文

PromptDock 的首个开源版本。

### 功能

- Windows 置顶提示词记录器。
- 支持多页面标签、顶部固定加号、自动保存和深浅主题。
- 支持 Prompt、Markdown、纯文本、JSON 和 JavaScript 高亮。
- 拖动到屏幕右侧约 30% 的区域后自动贴齐右边缘。
- 鼠标离开后平滑收起为 6px 边缘条，靠近屏幕右缘时自动展开。
- 拖动过程中不会反复吸附。
- 提供安装版和无需安装的便携版。

### 注意

当前二进制未配置商业代码签名证书，Windows 可能显示 SmartScreen 提示。

## English

The first open-source release of PromptDock.

### Highlights

- Windows always-on-top prompt notepad.
- Multi-page tabs, permanently visible add button, autosave, and light/dark themes.
- Prompt, Markdown, plain text, JSON, and JavaScript highlighting.
- Automatic right-edge snapping when dragged into the rightmost ~30% of a display.
- Smooth 6px edge collapse and pointer-triggered reveal.
- No repeated snap-back while dragging away from the docked edge.
- Installer and portable Windows builds.

### Notes

The binaries are not commercially code-signed, so Windows may display a SmartScreen warning.
