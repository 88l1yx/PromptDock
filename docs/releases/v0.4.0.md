# PromptDock v0.4.0

## 简体中文

### 新功能

- 右上角主题按钮旁新增窗口尺寸保存按钮。
- 调整窗口到合适大小后点击保存，下次启动会自动恢复该尺寸。
- 尺寸保存按钮带有保存中旋转、保存成功勾选回弹和失败抖动动画。
- 普通拖动缩放不会覆盖已保存尺寸，只有点击保存按钮才会更新。

## English

### New

- Added a save-size button next to the theme button.
- Resize the window, click save, and the next launch restores the saved width and height.
- The button includes spinning, success-pop, and error-shake animation states.
- Normal resizing does not overwrite the saved size; only clicking the button updates it.
